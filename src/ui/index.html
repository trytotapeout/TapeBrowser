          使用帮助

          地址栏能输入什么

          浏览 TapeKit 电路容器里的 DeWEB 网站。在上方地址栏输入：

          • 直接输数字就行：自动查找 1.888、18.88、188.8 所有组合，有首页的都打开，也可以写 1888.tape。数字更长时还会查带区号的组合，比如 12330 会查到 1.2.330（X Layer）、12.3.30（Base）
          • 打开 BNB Chain 上电路 #4454（处理器 0）的网站，也可以写 tape://4454-0、#4454@0
          • X Layer 和 Base 的网站在处理器编号前加区号：X Layer 是 2，Base 是 3。1.2.230 就是 X Layer 上 230 号处理器的 #1，也可以写 #1@2.230
          • 0x… 钱包地址：在三条链上扫描这个钱包持有的全部电路，有首页的都打开
          • 普通网址：https://… 照常打开

          从其他程序打开

          浏览器地址栏或网页链接里的 tape:// 地址会直接用 TapeBrowser 打开，第一次会询问是否允许。

          • 网页链接：<a href="tape://4454.0">
          • macOS 终端：open "tape://4454.0"

          要发到社交平台或聊天里，用网站信息面板里的「分享链接」：它是一个普通的 https 链接，装了 TapeBrowser 的人点开会直接打开网站，没装的会看到下载页。

          给站长：DeWEB 应用卡片的图片

          在网站根目录（和 index.html 同一层）放下面的图片，DeWEB 应用里就会显示。没有图片时显示标题首字。

          • logo.png 或 logo.jpg：正方形图标，推荐 256×256，最大 512×512，居中显示，PNG 可以用透明背景
          • cover.png 或 cover.jpg：16:10 封面，推荐 640×400，铺满卡片的图片区；有封面时不显示 logo
          • 每张不超过 50 KB，超过的不显示。目录每小时检查一次，换图后最多一小时更新

          给站长：DeWEB 应用的分类

          TapeBrowser 会按标题、描述和页面内容推测一个分类，卡片上标「推测」。想指定分类，在网站根目录放一个 deweb.json：

          • {"category": "game"}
          • 可选的值：game 游戏、finance 金融、tool 工具、social 社交与内容、infra 生态、other 其他

          链上校验

          钱包

          TapeBrowser 不保存私钥。网站的签名和交易会转给你在系统浏览器里打开的「钱包桥接页面」，由那里的钱包扩展（MetaMask 等）确认。使用钱包期间请保持桥接页面打开。

            内容缓存

            访问过的网站文件按 SHA-256 存在本机。每次打开仍会先查链上的最新版本，内容没变才用缓存；读链失败时显示上次缓存的版本。
