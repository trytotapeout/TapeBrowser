浏览器身份

一枚 TapeBrowser 电路就是一个身份。身份的资产和数据放在电路的容器里，电路转让后，容器里的资产也跟着转给新持有人。

TapeBrowser

浏览 TapeKit 电路容器里的 DeWEB 网站。在上方地址栏输入：

  • 打开 BNB Chain 上电路 #4454（处理器 0）的网站，也可以写 tape://4454-0、#4454@0
  • X Layer 和 Base 的网站在处理器编号前加区号：X Layer 是 2，Base 是 3。1.2.230 就是 X Layer 上 230 号处理器的 #1，也可以写 #1@2.230
  • 不带分隔符：查找 1.2330、12.330、1233.0、1.2.330（X Layer）、12.3.30（Base）等所有组合，有首页的都打开
  • 0x… 钱包地址：在三条链上扫描这个钱包持有的全部电路，有首页的都打开
  • 普通网址：https://… 照常打开

          设置

          钱包

          TapeBrowser 不保存私钥。网站的签名和交易会转给你在系统浏览器里打开的「钱包桥接页面」，由那里的钱包扩展（MetaMask 等）确认。使用钱包期间请保持桥接页面打开。

          已连接钱包的网站

            内容缓存

            访问过的网站文件按 SHA-256 存在本机。每次打开仍会先查链上的最新版本，内容没变才用缓存；读链失败时显示上次缓存的版本。

            语言

            RPC 节点

            每条链各自的读链节点，每行一个，按顺序轮换。留空使用内置公共节点。
