# TapeBrowser

浏览 TapeKit 电路容器里 DeWEB 网站的桌面浏览器（Electron），支持 macOS、Windows 和 Linux。网站文件直接从链上读取并校验，不经过任何网关服务器。

**欢迎一起共建。** 这是一个开源项目，修 bug、加功能、改文案、补翻译、在 Windows / Linux 真机上测试，都欢迎直接提 Issue 和 PR。比起各自维护分支，我们更希望改进能合并回这个仓库，让所有用户都能用上。怎么参与见 [CONTRIBUTING.md](CONTRIBUTING.md)。

## 下载

在 [GitHub Releases](https://github.com/trytotapeout/TapeBrowser/releases/latest) 下载最新版本：

| 平台 | 文件 |
| --- | --- |
| macOS（Apple 芯片） | `TapeBrowser-<版本>-mac-arm64.dmg` |
| macOS（Intel） | `TapeBrowser-<版本>-mac-x64.dmg` |
| Windows（x64） | `TapeBrowser-<版本>-win-x64-setup.exe` |
| Linux（x86_64） | `TapeBrowser-<版本>-linux-x86_64.AppImage` |

每个版本都附有 `SHA256SUMS.txt`，可以核对下载的文件。安装包还没有签名，第一次打开时：

- macOS：右键点应用选「打开」，或者在「系统设置 → 隐私与安全性」里允许
- Windows：SmartScreen 提示时点「更多信息 → 仍要运行」
- Linux：先 `chmod +x` 再运行 AppImage

## 地址栏能输入什么

| 输入 | 效果 |
| --- | --- |
| `4454.0`、`4454-0`、`#4454@0`、`tape://4454-0`、`4454.0.tape` | 打开 BNB Chain 上电路 #4454（处理器 0）的网站 |
| `1.2.344`、`1-2-344`、`#1@2.344`、`1.2.344.tape` | 打开 X Layer（区号 2）上 344 号处理器 #1 的网站；Base 区号是 3，例如 `1.3.5` |
| `12330`、`12330.tape`、`tape://12330` | 试所有切分（1.2330、12.330、123.30、1233.0，以及带区号的 1.2.330、12.3.30、123.3.0），有 `index.html` 的都开一个标签 |
| `0x…` 钱包地址 | 在三条链上扫描钱包持有的全部电路，容器已开通、有 `index.html` 的都开一个标签 |
| `https://…`、`example.com` | 普通网页照常打开 |

新标签页会显示书签和最近访问的电路网站（每个网站一条，最多记 200 个，存在本机 `library.json`）。

### 多链

TapeKit 网站分布在三条链上，命名规则和官方网关一致（tapekit.org）：BNB Chain 不带区号（`4454.0`），X Layer 区号 2（`1.2.344`），Base 区号 3（`1.3.5`）。区号 0、1 保留不用，未分配的区号会直接报错。

- 每条链有自己的合约和内置节点，设置里可以分别填自定义 RPC。X Layer 和 Base 的合约地址相同，同一个容器地址在两条链上按链分开读
- 数字枚举、钱包扫描、网站目录都对三条链并行查询，一条链的节点出问题不影响其他链，提示里会说明哪条链失败
- 网页里的 `window.ethereum`：钱包没连上时 `eth_chainId` 返回网站所在的链；网站第一次连接时，钱包不在网站所在的链上会请钱包切过去（钱包里没有这条链就先添加），用户拒绝也不影响连接。钱包当前的链和网站不一致时，地址栏右边的钱包按钮会显示 ⚠
- 地址栏左边「链上」按钮后面的标签显示当前网站所在的链，颜色取各链 logo 的主色：BNB Chain 黄色、X Layer 黑色、Base 蓝色

### 网站目录

新标签页的「全部网站」分栏列出链上所有容器已开通、有 `index.html` 的电路网站，可以按标题、电路编号或持有人地址搜索，按最近更新、电路编号或处理器排序。点击打开，⌘ 点击在后台标签打开。

目录由 TapeBrowser 自动维护，存在本机 `directory.json`：

- 第一次启动和之后每周做一次完整扫描：检查全部已铸造电路的容器是否开通（每批 400 个，批间限速），BNB 约三分钟
- 每小时增量检查一次，几秒完成：只查上次之后新铸造的电路、容器已开通但还没有首页的电路，以及已收录网站的首页更新和下线
- 很早铸造、很久以后才开通容器的电路，要等下一次完整扫描（最多一周）才会收录
- 标题取自首页的 `<title>`，按首页 SHA-256 缓存，首页没变不重新下载；超过 256 KB 的首页不下载，显示「（没有标题）」
- 也可以点「立即刷新」手动完整扫描

| 快捷键 | 功能 |
| --- | --- |
| ⌘F / ⌘G / ⇧⌘G | 页内查找 / 下一个 / 上一个 |
| ⌘+ / ⌘- / ⌘0 | 放大 / 缩小 / 实际大小 |
| ⌘D | 为当前网页添加或移除书签 |
| ⌘T / ⌘W / ⌘L | 新标签页 / 关闭标签页 / 地址栏 |

打开电路网站时，地址栏左侧的「链上」按钮会打开网站信息面板，显示持有人、容器、当前文件的 SHA-256、大小、上链时间和读取方式。

- **多节点交叉校验**：页面打开后，另外两个不同的节点各自读一遍「电路 → 容器」和当前文件的 SHA-256，和显示网页用的结果比对。不一致时「链上」按钮变红，显示「节点结果不一致」，面板里列出哪个节点读到了什么。单个节点作恶可以把文件和哈希一起伪造，交叉校验能发现这种情况
- **持有人变更提醒**：访问过的网站记下持有人。换了持有人（被转手或卖掉）时，再次打开会提醒，最近访问和书签里标「持有人已变」，面板显示上一任持有人
- **网站更新提示**：最近访问和书签里的网站，首页在上次访问之后更新了，标「有更新」（目录每小时检查）
- **持有的全部网站**：面板里持有人后面的「持有的全部网站」，在新标签页的全部网站里列出这个地址持有的所有网站
- **外部资源提示**：记录网站加载的非链上资源。外部脚本、接口、WebSocket 不受链上校验保护，「链上」按钮会显示「含外部脚本」，面板里列出地址
- **签名风险解读**：确认弹窗把常见操作翻成一句话，代币名称和精度直接从链上读。无限额授权、授权全部 NFT、Permit / Permit2 离线授权、Seaport 挂单、`eth_sign` 盲签标为高危：默认按钮是「拒绝」，也不能勾选「不再询问」。认不出的合约调用会明确提示「无法解读」
- **代码变更提醒**：每次同意签名后记下网站已加载文件的哈希；下次再签名时，如果有文件改过，弹窗会列出来。勾选过「不再询问」的网站遇到这种情况也会重新弹窗
- 这些只能降低风险：TapeBrowser 能证明内容来自链上、没被篡改，但判断不了网站作者本身有没有恶意

访问过的文件按 SHA-256 缓存在本机（`content-cache/`，上限 512 MB）。每次打开仍会先查链上该路径当前的哈希：哈希没变才用缓存，网站更新后马上能看到新内容。读链失败时会退回上次缓存的版本，地址栏按钮显示「离线缓存」。缓存可以在设置里清除。

网站地址的格式是 `tape://<ID>-<处理器>/路径`。主机名用连字符而不用点，因为 Chromium 会把 `4454.0` 这种全数字主机名当成 IPv4 地址。

## 连接钱包

TapeBrowser 不导入私钥，也不用 WalletConnect，而是通过系统浏览器里的钱包扩展签名：

1. 网页调用 `eth_requestAccounts`（或点工具栏的「连接钱包」），TapeBrowser 在系统浏览器中打开本机桥接页面 `http://127.0.0.1:47654/?t=<口令>`。
2. 在桥接页面选好钱包扩展（MetaMask 等，支持 EIP-6963）并授权。
3. TapeBrowser 弹窗确认是否把地址给这个网站。签名和交易同样先由 TapeBrowser 弹窗显示是哪个网站发起的，再交给钱包扩展确认。钱包扩展那边看到的来源只会是 127.0.0.1。

只读请求（`eth_call` 等）在 BSC 上走内置的公共 RPC 池，不经过钱包。已授权的网站可以在设置里取消授权。要断开钱包，在设置页或菜单「钱包 → 断开钱包」操作；网站授权会保留，重新连接后不用再确认。OKX 等不支持 `wallet_revokePermissions` 的钱包，扩展里对 127.0.0.1 的授权需要在扩展里手动移除。

## 界面语言

支持中文和英文，默认跟随系统语言（系统是中文时用中文，否则用英文），可以在设置里切换，切换后立即生效。

- 中文直接写在代码里，同时作为字典的 key；英文在 `src/i18n/en.json`。界面代码用 `tr('中文', { 占位符 })`
- 已经翻译：标签栏、地址栏、新标签页、网站信息面板、设置、菜单、通知、钱包确认弹窗、关于
- 还没有翻译（英文界面下仍显示中文）：钱包桥接页、tape:// 错误页、签名请求的内容说明
- `test/i18n.test.mjs` 检查界面里每一条中文都有英文翻译、占位符一致；新增文字漏写英文时测试会失败

## 开发

需要 Node 22.12 或更高版本（见 `.nvmrc`）。

```bash
npm install
```

```bash
npm start
```

```bash
npm test
```

```bash
npm run live
```

```bash
npm run dist:mac
```

```bash
npm run dist:win
```

```bash
npm run dist:linux
```

`npm run live` 是主网只读冒烟测试，需要联网。

打包产物都在 `dist/`：mac 是 Apple 芯片（arm64）和 Intel（x64）两个 `.dmg`，Windows 是 x64 的 `.exe` 安装包，Linux 是 x64 的 `.AppImage`。文件名统一为 `TapeBrowser-<版本>-<平台>-<架构>`，例如 `TapeBrowser-0.8.2-mac-x64.dmg`。三个平台都可以在 mac 上直接交叉打包，不需要装 Wine；`npm run dist:all` 依次打全部三个。

打包产物都没有签名：mac 第一次打开时 Gatekeeper 会拦截，需要右键选择「打开」；Windows 会弹 SmartScreen 提示，点「更多信息 → 仍要运行」；Linux 的 AppImage 需要先 `chmod +x` 再运行。

## 代码结构

- `src/main/`：主进程。`tape-protocol.js` 负责从链上读取并校验文件，`sites.js` 负责枚举和钱包扫描，`bridge-server.js` 是钱包桥接服务，`provider-host.js` 处理网页的 EIP-1193 请求，`tabs.js` 管理标签页。
- `src/preload/`：`tab.cjs` 往网页注入 `window.ethereum`，`ui.cjs` 是外壳界面的 IPC。
- `src/ui/`：标签栏、地址栏和设置界面。
- `src/bridge/`：在系统浏览器里打开的钱包桥接页面。

## 安全说明

- 桥接服务只监听 127.0.0.1，页面和 WebSocket 都要求口令，同时校验 Host 和 Origin。口令保存在本机的 settings.json 里（文件权限 0600）。
- 网页的权限请求只放行全屏和剪贴板写入。
- 网页可以访问外部 http/https 地址，跟普通浏览器一样。
