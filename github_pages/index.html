TapeBrowser

基于 TapeKit DeWEB 的应用浏览器，跨平台，但不仅仅是浏览器。

下载 0.15.0 查看源代码

macOS · Windows · Linux｜GPL-3.0-or-later 开源

DeWEB 特性

普通浏览器做不到、只有去中心化网站才需要的能力。

tape:// 直接读链

网站文件存在 TapeKit 电路的链上容器里，TapeBrowser 直接从公共节点读取，不依赖任何网关服务器。

按电路名访问

输入 4454.0、#4454@0、1.2.248（X Layer）或 8888.tape 都能打开同一个网站。

分享链接

网站信息面板一键复制 https 分享链接，能发到 X、Telegram、微信。装了 TapeBrowser 的人点开直接打开网站，没装的看到下载页。

数字串和钱包地址

输入 42460 这样的数字串，自动尝试所有切分；输入钱包地址，打开它在三条链上持有的所有网站。

三条链

BNB Chain、X Layer（区号 2）、Base（区号 3）并行查询，各自的节点池，地址栏显示网站所在的链。

哈希校验

每个文件下载后都核对长度和链上记录的 SHA-256，节点或网络篡改了内容会直接拒绝显示。

多节点交叉校验

再找两个不同的节点核对容器和文件哈希，单个节点作恶伪造不了，不一致时按钮变红。

持有人变更提醒

网站换了持有人（被转手或卖掉）时，再次打开会提醒，书签和最近访问里也会标出来。

安全体检

一键读取网站的全部文件，在本机分析它会请你签什么、钱会流向哪里，以及有没有骗助记词、盗币工具包等作恶特征。

本地预览和发布预检查

打开本机文件夹，按 tape:// 的规则预览网站，上链前列出传不上去、打不开、目录里显示不好的问题和要发的交易笔数。

发布到容器（实验）

预览满意后一键发到自己电路的容器，没开通的顺带开通。钱包通常只确认 2 到 3 笔，之后临时钱包自动上传、核对，剩下的 Gas 退回。

签名风险解读

无限额授权、授权全部 NFT、离线签名授权、盲签等高危请求翻成一句话，默认按钮是「拒绝」。

外部脚本和代码变更

网站运行了不在链上的脚本时标出来；上次签名之后网站改过代码，签名时列出改了哪些文件。普通网页标「未校验」。

钱包不导入私钥

桥接系统浏览器里的钱包扩展（MetaMask 等），不依赖 WalletConnect 这类中心化中继，每次签名都先显示真实来源；链不对时一键切换。

DeWEB 应用

新标签页以卡片列出三条链上所有有首页的网站，显示站长的 logo 或封面，按游戏、金融、工具等分类筛选，也能按标题、编号、持有人搜索。

BEM 价格和资产

工具栏显示 BEM 价格和钱包在两条链上的 BEM 总数；网站信息面板显示容器里的原生币和 BEM。都直接从链上读。

打赏

喜欢的网站可以用钱包直接打赏 BEM 到网站的容器，只付网络 gas，打赏公开记录在链上。

新上线

新标签页列出最近 7 天第一次发布的网站，按首页上链时间排序，新网站一上线就能被看到。

离线兜底

文件按 SHA-256 缓存在本机，每次仍先查链上最新版本；读链失败时显示上次缓存的版本。

TapeBrowser 能证明你看到的内容来自链上、没有被篡改，但判断不了网站作者本身有没有恶意。签名和交易前请自己核对。

0.15.0 2026-10-10

  • 检查更新：启动时检查有没有新版本（一天最多一次），有新版本时弹窗提示，点「去下载」打开 GitHub 发布页，也可以跳过这个版本。只提示、不自动下载安装。菜单里的「检查更新…」可以随时手动检查
0.13.0 及更早的版本怎么打开

0.13.0 及更早的版本第一次打开时：

  1. 打开下载的 dmg，把 TapeBrowser 拖进「Applications」（应用程序），再双击打开。系统会提示「Apple 无法验证」，点「完成」。

  2. 打开「系统设置 → 隐私与安全性」，滚到「安全性」一栏，在「已阻止 TapeBrowser.app 以保护 Mac」旁边点「仍要打开」，输入密码确认。之后就能正常打开了。

如果提示的是「已损坏，无法打开」（0.9.0 及更早的版本会这样），在终端运行 xattr -dr com.apple.quarantine /Applications/TapeBrowser.app 后再打开。

更早的版本

0.14.0 2026-10-10

  • macOS 安装包用 Apple 开发者证书（Developer ID）签名，并通过 Apple 公证，下载后双击就能打开，不用再去系统设置里点「仍要打开」
  • 不再提供 macOS Intel 版本，只提供 Apple 芯片版本。Intel 芯片的 Mac 可以继续使用 0.13.0
  • 发布到容器（实验功能）：本地预览的预检查面板里点「发布到容器…」，选链（BNB Chain / X Layer）和自己的电路，先看发布计划和预估花费，再一键上传。没开通容器的电路可以顺带开通。钱包通常只需确认 2 到 3 笔交易（开通、授权临时钱包 6 小时、充值 Gas），之后由临时钱包自动上传，发完核对链上内容并退回剩下的 Gas
  • 发布可以暂停、中断后接着发；链上已经有的相同文件直接复用，不重复上传。临时钱包的私钥用系统钥匙串加密保存在本机，不能导出
  • 链上文件只增不改：内容变了的文件要换文件名，只有首页 index.html 可以在最后整个替换。预检查会提示首页超过一块（24000 字节）时替换要分几笔、替换期间网站会暂时打不开
  • 发布功能还没有在真实网络上完整测试过，开通费和 Gas 是真实花费，建议先用一个小网站在 X Layer 上试一次

0.13.0 2026-10-09

  • 安全体检：网站信息面板里点「开始体检」，读取网站的全部文件在本机分析：会请你签哪些操作（授权、无限额授权、Permit、Seaport 挂单、盲签）、代码里写死的地址是合约还是普通钱包，以及骗助记词、盗币工具包、回传数据、劫持钱包、远程加载代码等作恶特征。规则用目录里全部 85 个网站校准过
  • 本地预览和发布预检查：菜单「文件 → 打开本地文件夹预览」（⌘O），上链前按 tape:// 的规则预览网站，文件改了自动刷新；预检查列出传不上去、上链后打不开、目录里显示不好的问题，以及要发多少笔交易
  • 不在链上的网站标「未校验」：普通网页的地址栏左边显示灰色的「未校验」，连接钱包、签名时也会提醒内容不在链上
  • 站长声明分类的文件改名为 deweb.json
  • 新标签页、产品网站和分享落地页换成更朴素的样式：暖白底、白色卡片、细边框，去掉渐变和阴影
